How these pages work

Read and lookThe notes follow the printed handout, with diagrams that show what Python is doing.
Try itSliders, step-through tracers and quick checks let you test your understanding as you read.
Run real PythonEvery code block opens a live Python window under it, and empty boxes are there for your own code. The first start takes 10–20 seconds.
PractiseEach week ends with a full Jupyter notebook and a challenge. Use File → Download to keep your work.
