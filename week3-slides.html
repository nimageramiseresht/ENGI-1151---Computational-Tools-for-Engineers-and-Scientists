1Modules, packages and libraries

modulepackagelibrary

module

one Python file (.py) with functions you can import

package

a folder that groups related modules

library

a general word for a collection of reusable code; it can contain packages and modules

People often use the three words loosely.

One of Python's main strengths is its ecosystem of modules, packages and libraries: tested code for common jobs, so we can focus on the engineering problem. Module: a single .py file with definitions (functions, classes) that another program can import. Package: a structured collection of modules, organised in folders. Library: general word for a collection of reusable code for a range of tasks; may contain several packages and modules. Matplotlib example: the library contains the matplotlib package, which contains modules such as pyplot, cm and colors; pyplot contains plot(), scatter(), xlabel(), savefig(). import matplotlib.pyplot as plt loads one module: importing does not load every part of a library into memory. People use the three words loosely: don't worry about the exact boundary.

4.1NumPy arrays

ndarraydimensionshape

import numpy as np

a = np.array([1, 2, 3, 4])
print(a)

b = np.array([
    [2, 3, 5],
    [7, 12, 1]
])
print(b)
The central NumPy object is the ndarray: an n-dimensional array. Used for datasets, vectors and matrices, time series, discretised spatial domains, images. Create a 1-D array from a list with np.array([...]); a 2-D array from a nested list: one inner list per row. b has 2 rows and 3 columns: shape (2, 3). Arrays can have more dimensions, hence "n-dimensional". Run it: NumPy prints arrays without commas and lines the columns up. axis 0 runs down the rows, axis 1 runs across the columns: we will use these names for statistics later.

4.2Array data types

dtypeint64float64

Arrays can also hold Booleans, complex numbers and strings, but the speed comes from one numerical type.

import numpy as np

integer_array = np.array([1, 2, 3])
float_array = np.array([1.0, 2.0, 3.0])
mixed_array = np.array([1, 2.5, 3])
print(integer_array.dtype)
print(float_array.dtype)
print(mixed_array.dtype)

values = np.array([1, 2, 3], dtype=float)
print(values)
Unlike a list, an array stores all its elements with one common data type, the dtype. Mixing integers and floats: NumPy picks a type that can hold all of them, float64, so [1, 2.5, 3] becomes [1. 2.5 3.]. You can ask for a type with dtype=float. Note for the live boxes: the browser version of Python is 32-bit WebAssembly, so the integer dtype may print as int32 instead of int64 as on a laptop. Same idea: a fixed-size whole number. Arrays can store Booleans, complex numbers, strings or Python objects, but the performance benefit comes from a consistent numerical type.

5.4np.meshgrid(): from two vectors to a grid

  
discretisegrid pointcoordinate arrays X, Y

  

    
    
  

  

    

      
      

    

    

      
X x copied down every row

      
      
Y y copied across every column

      
      

    

  

  

Many engineering problems need a function of TWO variables evaluated over an area: a plate, a cross-section, a terrain. The computer cannot work with infinitely many points, so we discretise: cut the x range and the y range into a finite number of points.
Slide the controls: x = np.linspace(0, 3, nx) cuts the x axis into nx points (blue), y = np.linspace(0, 2, ny) cuts the y axis into ny points (orange). Every crossing is a grid point: nx × ny points in total.
np.meshgrid(x, y) returns two 2-D arrays with shape (ny, nx), one entry per grid point: X holds the x-coordinate of each point (x copied down every row), Y holds the y-coordinate (y copied across every column).
Click a point: its coordinates are X[i, j] and Y[i, j]: same row i, same column j in both arrays. Note row 0 is the bottom line of points (y = 0) while it prints at the top of the array.
More points = finer discretisation = smoother result, but more calculations.
The code panel under the arrays updates with the sliders: it is exactly the NumPy code for the grid shown. Then a function of two variables is one line: Z = X**2 + Y**2 computes every point at once (handout example uses x = [1, 2, 3], y = [4, 5]: Z top-left = 1² + 4² = 17).

6.1Element-wise operations

  
element-wisevectorisednp.sin()

  

    

      
      
Functions work element-wise too: np.sin(array) returns an array. sin(π) prints 1.22e-16, not 0: np.pi is only an approximation (week 1 floating point).

    

    
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print(a + b)
print(a - b)
print(a * b)
print(a / b)

angles = np.array([0, np.pi / 2, np.pi])
print(np.sin(angles))


  

  

NumPy arithmetic acts element by element: a + b adds the elements in the same position. Same for -, *, /. No loop: this is called vectorised code, and it is much faster than a Python loop over a list.
* between two arrays is element-wise multiplication: the shapes must be compatible (equal, for now).
Passing an array to a NumPy function, like np.sin, applies the function to every element and returns a new array.
sin(π) should be exactly 0 but prints 1.2246468e-16: floating-point precision again; np.pi is an approximation. Because that one value is tiny, NumPy prints the whole array in scientific notation.
  







  
6.2Matrix multiplication with @

  
@ matrix product* element-wisetranspose .T

  

    

      

        
        
      

      

      

      
Shapes: (2, 3) @ (3, 2) → (2, 2). The inner sizes must match; the outer sizes give the result.

    

    
import numpy as np

A = np.array([[2, 4, 5],
              [3, 1, 6]])
B = np.array([[1, 4],
              [0, 3],
              [2, 5]])

print(A @ B)
print(A.T)
print(A * B)


  

  

@ performs matrix multiplication. For 2-D arrays the number of columns of the first must equal the number of rows of the second.
Each result element = row of A times column of B, multiplied pair by pair and added. Click a number in the result on the left to see the calculation, e.g. C[0, 0] = 2×1 + 4×0 + 5×2 = 12.
Switch to * : element-wise multiplication needs arrays of the same shape and multiplies matching positions.
Transpose: A.T or np.transpose(A) swaps rows and columns.
Run the box: A @ B gives [[12 45] [15 45]], A.T is 3 × 2, and A * B fails with ValueError because shapes (2, 3) and (3, 2) do not match. The most common NumPy error message: read the shapes it reports.

6.4Sorting

  
np.sort(): a copy.sort(): in place

  

    
    
import numpy as np

a = np.array([3, 1, 4, 2])
sorted_a = np.sort(a)
print(sorted_a)
print(a)          # unchanged

a.sort()          # sorts a itself
print(a)

m = np.array([[3, 1, 2],
              [6, 4, 5]])
print(np.sort(m, axis=1))


  

  

np.sort(a) returns a sorted COPY: the original array is unchanged.
The method a.sort() sorts the array IN PLACE: it changes a and returns None (so do not write a = a.sort()).
For 2-D arrays choose the axis: axis=1 sorts each row separately; axis=0 sorts down each column (in the handout example nothing changes with axis=0 because every column is already in order).
Engineering use: sorting measurements to find percentiles or the worst cases.

7.4Figures and axes: fig, ax

  
plt.subplots()figureaxes

  

    
    
plt.plot() → ax[0].plot()
plt.title() → ax[0].set_title()
plt.xlabel() → ax[0].set_xlabel()

  

  
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, np.pi, 100)
fig, ax = plt.subplots(nrows=1, ncols=2)
ax[0].plot(x, np.sin(x))
ax[0].set_title("Sine Wave")
ax[0].set_xlabel("Angle, x [rad]")
ax[0].grid(True)
ax[1].plot(x, np.cos(x))
ax[1].set_title("Cosine Wave")
ax[1].set_xlabel("Angle, x [rad]")
fig.tight_layout()     # stop the plots overlapping
plt.show()


  

For more control, create the figure and axes explicitly: fig, ax = plt.subplots(nrows=1, ncols=2).
It returns two things: fig, the complete figure, and ax, an array of axes (plotting areas), here two in one row: ax[0] on the left, ax[1] on the right.
Plotting and formatting are applied to each axes object separately. The names change slightly: plt.title() becomes ax[0].set_title(), plt.xlabel() becomes ax[0].set_xlabel().
This object-oriented style is the one to use for multiple subplots and complex figures, e.g. stress and deflection side by side.
Handout version also sets y labels and turns the grid off on the right plot. fig.tight_layout() is an extra here: it adjusts the spacing so the two plots do not overlap.
  







  
8Three-dimensional surface plots

  
z = f(x, y)plot_surface()colourmap

  
  
import numpy as np
import matplotlib.pyplot as plt
from matplotlib import cm

x = np.linspace(-5, 5, 100)
y = np.linspace(-5, 5, 100)
X, Y = np.meshgrid(x, y)
Z = np.sin(np.sqrt(X**2 + Y**2))

fig, ax = plt.subplots(subplot_kw={"projection": "3d"})
surface = ax.plot_surface(X, Y, Z, cmap=cm.viridis)
fig.colorbar(surface, shrink=0.6, pad=0.12)
ax.set_xlabel("x")
ax.set_ylabel("y")
ax.set_zlabel("z")
plt.show()


  

A surface plot shows a function of two variables, z = f(x, y): everything from today comes together.
linspace cuts each axis into 100 points; meshgrid makes the 100 × 100 grid; Z is calculated at every grid point in one line (element-wise); plot_surface draws it.
The 3-D axes come from plt.subplots(subplot_kw={"projection": "3d"}). There is no plt.surface() function.
cmap sets the colourmap (viridis here; try cm.coolwarm). fig.colorbar adds the scale linking colours to values: keep the object returned by plot_surface and pass it in (pad moves the bar away from the z axis). The handout version has no colour bar.
This image is static; to look from another angle add ax.view_init(elev=40, azim=30) before plt.show() and run again. The surface at the top of week3.html can be rotated by dragging.
Rendering 10 000 points takes a few seconds in the browser.

print(readings.shape)
sensor_max = np.max(readings, axis=1)     # one value per sensor
for number, peak in enumerate(sensor_max, start=1):
    if peak > safe_limit:
        print('temperature exceeded the safe limits on sensor number',
              number)

hours = np.arange(24)
hourly_max = np.max(readings, axis=0)     # one value per hour
limit = safe_limit * np.ones(24)

plt.plot(hours, hourly_max, color="black", label="hottest sensor")
plt.plot(hours, limit, color="red", linestyle="--", label="safe limit")
plt.xlabel("Hour")
plt.ylabel("Temperature [°C]")
plt.legend()
plt.show()


  

Walk through: shape (15, 24). axis=1 travels along each row → 15 maxima, one per sensor. The for loop with enumerate(start=1) gives sensor numbers 1–15, exactly as in week 2; sensors 4, 9 and 13 exceed the limit.
axis=0 travels down the columns → 24 values, the hottest reading in each hour. np.ones(24) times the limit makes a flat line for plotting.
The plot shows when in the day the limit was crossed: around hours 10, 13 and 14–15, the hottest part of the working day.
