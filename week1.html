1Introduction

In modern engineering, programming is becoming an essential skill across all disciplines. Whether working with data, building simulations, automating calculations, or even controlling hardware, good programming skills can make your work significantly more efficient. Programming languages can be classified according to their level of abstraction from the computer hardware. While all programming languages ultimately generate machine instructions, they differ in how much control they provide over the hardware and how easy they are for humans to use.

Languages such as C and Fortran are often considered lower-level high-level languages. They provide efficient execution and greater control over memory and data structures, making them particularly suitable for operating systems, embedded systems, and high-performance scientific computing. However, they typically require more detailed management of program structure, memory, and data types.

In contrast, Python is a high-level, interpreted language that emphasises readability, ease of development, and programmer productivity. Many tasks that require dozens of lines of code in C or Fortran can often be implemented in only a few lines of Python. Python automatically manages memory and provides a large collection of libraries for numerical computation, data analysis, visualisation, optimisation, and machine learning.

1.1 Why Python?

Although Python programs may execute more slowly than equivalent programs written in C++ or Fortran, much of the computationally intensive work is performed by highly optimised libraries implemented in compiled languages. As a result, Python combines ease of use with powerful computational capabilities, making it one of the most widely used programming languages in modern engineering and scientific research.

For these reasons, Python will be used throughout this module. Its readability allows us to focus on understanding algorithms and solving engineering problems without becoming distracted by low-level implementation details, while still providing access to high-performance scientific computing tools when required. Also, Python is widely used in fields such as machine learning, data science, robotics, web development, and scientific computing, all of which are instrumental in scientific and engineering courses.

Python comes with an extensive standard library and a vibrant community, which means that if you’re trying to solve a problem, chances are someone has already written a Python package to help you do it. From numerical computations with NumPy to plotting data with Matplotlib to analysing data with Pandas, Python offers tools for almost every engineering task.

1.2 What is Jupyter Notebook?

As you’re learning to code, having an interactive and easy-to-use environment makes a big difference. This is where Jupyter Notebook comes in.

Jupyter Notebook is an open-source web-based interface that allows you to write and run Python code in small blocks called cells. Each cell can contain code, comments, or even formatted text and mathematical equations using Markdown and LaTeX. This makes it ideal for learning and experimentation because you can test individual parts of your code, see the output immediately, and document your work all in one place.

Another benefit of Jupyter is that it supports interactive visualisations, which is particularly useful in engineering when dealing with graphs, simulations, or data plots. It’s also the preferred environment for many researchers and data scientists, so learning how to use it early in your studies will be an advantage. Jupyter Notebook is also a common environment for cloud computing platforms, like Google Colab and Amazon AWS. So it will be worthwhile to learn how to work with it from the beginning.

2.5 Cells or code blocks in Jupyter Notebook

In a Jupyter Notebook, content is organised into cells. Cells can contain Python code (or other supported programming languages) as well as descriptive text. Each cell can be edited and executed independently. The two most commonly used cell types are:

  • Code cell: contains executable code. When the cell is run, the output is displayed directly below the cell.
  • Markdown cell: contains formatted text, such as headings, lists, equations, images, and explanations that document the code and results.

To create a new cell, click the + button in the toolbar. A new cell will be inserted below the currently selected cell. Code cells can be executed by pressing Shift + Enter. The notebook will run the code and display the resulting output beneath the cell.

Order of operations

The order in which operations are evaluated is important. Python follows the standard mathematical order of operations. In particular, expressions inside parentheses are evaluated first, followed by exponentiation, multiplication and division, and then addition and subtraction.

For example, 5 + 2 * 5 produces a different result from (5 + 2) * 5:

15
35

Using parentheses can make the intended order of operations clearer, even when they are not strictly necessary.

What does Python give for 2 + 3 * 4 ** 2?

4 ** 2 is done first (16), then 3 * 16 (48), then 2 + 48, which is 50.

What is 17 % 5?

17 = 5 × 3 + 2. Floor division 17 // 5 gives the 3, and modulo 17 % 5 gives what is left over, 2.

3.1.1 Variable names

Variable names should describe the quantities that they represent. For example, pipe_radius is usually more informative than r, particularly in a long engineering program. Although short variable names such as x, y, and t are acceptable when their mathematical meanings are clear, descriptive names generally make programs easier to understand and maintain. Python variable names must follow these rules:

  • A variable name may contain letters, numbers, and underscores.
  • A variable name cannot contain spaces. For example, use surface_area rather than surface area.
  • A variable name cannot begin with a number. For example, 2nd_value is invalid, whereas second_value is valid.
  • A variable name cannot contain characters such as @, #, %, or -.
  • Python keywords, such as if, for, while, and class, cannot be used as variable names.
  • Names of built-in Python functions and types, such as list, int, sum, and max, should not be used as variable names.
  • Variable names are case-sensitive. Therefore, temperature, Temperature, and TEMPERATURE are three different names.

For variable names containing multiple words, Python commonly uses snake case, in which words are separated by underscores. Examples include surface_area, fluid_density, and maximum_stress.

3.2Data types in Python

Every value in Python has a data type. The data type tells Python what kind of information the value represents and which operations can be applied to it. The following data types are commonly used:

  • Integer (int): a whole number without a decimal point, such as 1, -4, or 100.
  • Floating-point number (float): a real number represented using floating-point arithmetic, such as 3.14, -0.001, or 2.0. Floating-point numbers can also be written using scientific notation. For example, 1.5e-3 represents \(1.5 \times 10^{-3}\).
  • Complex number (complex): a number containing real and imaginary parts. Python uses j for the imaginary unit, as in 2 + 3j.
  • String (str): a sequence of characters enclosed in quotation marks, such as "hello" or 'Python'.
  • Boolean (bool): a logical value that is either True or False.
  • List (list): an ordered and changeable collection of values. A list can contain values of the same type or of different types.
  • Dictionary (dict): a collection of key–value pairs. Each key in a dictionary must be unique, but different keys can have equal values.

The built-in type() function can be used to determine the type of a value or variable:

<class 'float'>

The numerical data type can affect the result of an operation. For example, the division operator / always returns a floating-point value:

5.0
<class 'float'>

Floating-point values are stored with finite precision. Consequently, some decimal numbers cannot be represented exactly by a computer. This behaviour is a consequence of binary floating-point representation. This is important in scientific computing, particularly when comparing calculated values or assessing numerical errors. For example, 0.1 + 0.2 may produce:

0.30000000000000004

What is type(24 / 2)?

/ always returns a float, even when the answer is a whole number: 24 / 2 is 12.0. Use // if you want an integer.

What is type("3.14")?

The quotation marks make it text. It looks like a number, but Python treats it as a string until you convert it (next section).

3.3Type conversion

Python provides built-in functions for converting compatible values between data types:

  • float(value) converts a compatible value to a floating-point number.
  • int(value) converts a compatible value to an integer.
  • str(value) converts a value to a string.
  • bool(value) converts a value to a Boolean value.

4Collections: lists and dictionaries

4.1 List elements

A list stores an ordered collection of elements. The elements of a list are accessed by placing an integer index inside square brackets after the name of the list: list_name[index]. For example:

5
['John', 12]
John

The expression example_list[3] returns the nested list ['John', 12]. The expression example_list[3][0] first selects the nested list and then selects its first element.

Python uses zero-based indexing. Therefore, the first element of a list has the index 0, the second element has the index 1, and so forth. Negative indices can be used to access elements from the end of a list:

  • list_name[-1] returns the last element.
  • list_name[-2] returns the second-to-last element.
  • list_name[-3] returns the third-to-last element.
10
40
30

A range of list elements can be accessed using slicing. The general form is list_name[start:stop:step]. The element at the start index is included, but the element at the stop index is excluded. For example:

[20, 30, 40]
[10, 20, 30]
[30, 40, 50, 60, 123]
[10, 30, 50, 123]
