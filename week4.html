1Introduction

A function is a named and reusable block of code that performs a specific task. It can receive input values, process them, and return a result. For example, an engineering function could receive the radius and height of a cylinder and return its volume. Functions help us to:

  • avoid repeating code;
  • divide a program into smaller and more manageable parts;
  • make code easier to read and understand;
  • reuse calculations in different parts of a program; and
  • represent engineering equations clearly.

A well-designed function should normally perform one clearly defined task. You have already used many functions written by other people: print(), type(), len(), range(), np.mean() and plt.plot(). This week you write your own.

Python function names normally use snake case: a naming convention where spaces are replaced with underscores (_) and all letters are written in lowercase.     10Common errors

    Four mistakes cause most problems with functions. Open each tab to see the broken code, the message Python gives, and the fix.

    Calling a function before defining it: a function must be defined before the corresponding function call is executed. Python runs from top to bottom (week 2), so the def line has not run yet.

    NameError: name 'cube' is not defined

    Fix: move the def block above the call. In a notebook, also make sure the cell containing the def has been run.

    Forgetting parentheses: writing the function’s name without any parentheses after it refers to the function, rather than calling it. There is no error message, which makes this mistake easy to miss.

    <function greet at 0x7f3a5c2d1e40>

    Fix: add the parentheses: greet(). (The hexadecimal number is the function’s memory address, and will be different on your computer.)

    Using an incorrect number of arguments: if a function requires two arguments, both must be supplied unless one has a default value.

    TypeError: calculate_force() missing 1 required positional argument: 'acceleration'

    Fix: supply every required argument, calculate_force(10.0, 9.81), or give the parameter a default value, def calculate_force(mass, acceleration=9.81):. Too many arguments also raises a TypeError.

    Confusing displayed and returned values: a function that prints a result does not necessarily return that result.

    78.53975
TypeError: unsupported operand type(s) for *: 'NoneType' and 'float'

    Fix: for reusable engineering calculations, return the calculated value and display it separately when required, as in calculate_area_return().

    You run v = calculate_cylinder_volume and then print(v * 2). Which error do you get?

    Without parentheses, v is the function itself, not a number, and a function cannot be multiplied by 2: TypeError: unsupported operand type(s) for *: 'function' and 'int'.
