Functions help us to

A good function does one clearly defined task.

A function is a named, reusable block of code that performs a specific task. It can receive inputs, process them and return a result. Example: a function that takes the radius and height of a cylinder and returns its volume. Benefits: no repeated code; programs divided into manageable parts; easier to read; calculations reused; equations written clearly. You have already used many functions written by others (print, type, len, range, np.mean, plt.plot). Today you write your own. A well-designed function performs one clearly defined task.

2Defining a function

deffunction nameparametersbody

def greet():
    print("Hello, welcome to programming!")

# greet()

Remove the # before greet() and run again.

A function is defined with the def keyword: def function_name(parameters): followed by the indented body. Header: def, the function name, brackets containing the parameters (inputs) if there are any, and a colon. The body is indented exactly like the body of an if or a loop. Names: describe the task; Python uses snake_case (lowercase words joined by underscores): calculate_area, convert_temperature. Variable naming rules from week 1 apply. Run the box: nothing is printed. Defining a function does not execute it. Uncomment greet() and run: now the body runs.

2Calling a function

callcase-sensitive

Python skips the body at the def, then jumps into it at every call, and comes back after.

def greet():

To run the body, call the function: its name followed by brackets containing any required arguments. Functions receive inputs through parameters. In the definition, name is a parameter: the name the function uses for its input. In the call, "Alice" is an argument: the actual value supplied. def calculate_force(mass, acceleration):
    force = mass * acceleration
    print("Force:", force, "N")

calculate_force(10.0, 9.81)
calculate_force(mass=10.0, acceleration=9.81)

Positional arguments are matched by order. Swapped values usually give a wrong answer with no error; keyword arguments protect you.

    

  

  

A function can have several parameters, separated by commas.
Positional arguments are assigned by position: 10.0 → mass, 9.81 → acceleration.
Keyword arguments name the parameter: mass=10.0. Their order can then change. They make calls with several numbers much easier to read and check.
Use the widget: try 9.81, 10.0 (swapped: here the same answer only because multiplication does not care about order; for most equations it would be wrong with no error message), leave one out (TypeError: missing argument), give three (TypeError), or put a positional after a keyword (SyntaxError).
The long tail of digits (98.10000000000001) is the floating-point precision from week 1.

A function returns a result with the return statement.
Step through: the call add(3, 5) jumps into the function with a = 3, b = 5; result = 8; return sends 8 back; the call is replaced by 8 and stored in total.
When Python executes return, the function ends immediately: any statements after it in the function are not run.

3return versus print()

  
displayreturnNone

  

    

      
      
A function with no return returns the special value None.

    

    
def display_area_print(radius):
    area = 3.14159 * radius**2
    print(area)

def calculate_area_return(radius):
    area = 3.14159 * radius**2
    return area

volume = calculate_area_return(5.0) * 10.0
print(volume)

x = display_area_print(5.0)
print(x)


  

  

print() displays a value on the screen; return sends a value back to the part of the program that called the function.
A returned value can be stored and used in another calculation: area × 10.0 gives the volume 785.3975. For engineering calculations, returning is normally more useful than only displaying.
Quick check before running: what does print(x) show? The call prints 78.53975 (from inside the function), but the function has no return, so x is None.
  







  
4Returning more than one value

  
tupleunpacking

  

    

      
    

    
def basic_operations(a, b):
    addition = a + b
    subtraction = a - b
    multiplication = a * b
    if b == 0:
        division = None
    else:
        division = a / b
    return addition, subtraction, multiplication, division

print(basic_operations(3, 5))

add, sub, mul, div = basic_operations(3, 5)
print(add, sub, mul, div)


  

  

A function can return several comma-separated values. Python packs them into a tuple: an ordered collection like a list, written with round brackets, that cannot be changed after it is created.
They can be assigned to separate variables in one line: unpacking. The order of the variables must match the order in the return statement, and the number must match, otherwise ValueError.
Note the input check: if b == 0, division is set to None instead of dividing, so no ZeroDivisionError. Try basic_operations(10, 0). Input checks come back in section 6.2.

6Pass values in as parameters

  
global variableparameterreusable

  

    

      
works, but hidden input

        
gravity = 9.81            # global

def calculate_weight(mass):
    return mass * gravity

      
clearer: every input is a parameter

        
def calculate_weight(mass, gravity):
    return mass * gravity

      
The same function now works on the Moon: gravity=1.62.

    

    
def calculate_weight(mass, gravity):
    weight = mass * gravity
    return weight

weight = calculate_weight(mass=10.0, gravity=9.81)
print(weight)

print(calculate_weight(mass=10.0, gravity=1.62))


  

  

A function can read a global variable (gravity defined outside). It works, but the input is hidden: you cannot see from the call that the result depends on gravity.
Clearer: pass every required value as a parameter. The inputs are visible in the call, and the function is easier to reuse with different values: Earth 9.81, Moon 1.62.
Note: the global weight and the local weight inside the function are two different variables that happen to share a name.
  







  
6.1Default parameter values

  
default valueoptional argument

  

    

    

      
If no argument is given, Python uses the default. Parameters with defaults go last.

      
import numpy as np

def calculate_cylinder_volume(radius,
                              height=10.0):
    return np.pi * radius**2 * height

print(calculate_cylinder_volume(2.0))
print(calculate_cylinder_volume(2.0, 5.0))


    

  

  

A parameter can be given a default value: height=10.0. If the caller does not provide that argument, Python uses the default; the caller can still pass a different value.
Step through: the first call uses height = 10.0 (default), the second height = 5.0.
Rule: all parameters without defaults must come before parameters with defaults. def f(height=10.0, radius): is a SyntaxError: parameter without a default follows parameter with a default. Demo: swap them in the box.
  







  
6.2Checking function inputs

    import numpy as np

def calculate_cylinder_volume(radius, height=10.0):
    if radius < 0:
        print("The radius must not be negative.")
        return None
    if height < 0:
        print("The height must not be negative.")
        return None
    return np.pi * radius**2 * height

volume = calculate_cylinder_volume(radius=-2.0,
                                   height=5.0)
print(volume)

    
  
    
  
    
A function can check its inputs before calculating: a cylinder cannot have a negative radius or height.
If a check fails, the function prints a message and returns None: a signal that it did not produce a valid result. return ends the function, so the rest is skipped.
Use the widget: drag the radius below zero; untick "pass a height" to see the default fill in; drag the height below zero.
This simple input checking prevents some invalid engineering calculations from silently giving numbers.

    One expression only; its value is returned automatically. For longer calculations, conditions or docstrings, use def.
    
    
    
    
    import numpy as np

add = lambda a, b: a + b
print(add(3, 5))

print(kn_to_n(2.5))

A lambda is a short function defined in one line: lambda parameters: expression.
It contains a single expression whose value is returned automatically, with no return keyword. add = lambda a, b: a + b is equivalent to the def version.
Useful for short unit conversions and simple formulas. For anything longer, with if statements, or needing documentation, use def.

    9Nested functions: who can see what, and why
    
  
    enclosing scopehelper function
    
  
    
    
    
      
      
      
        
    1. Shared inputs: the helpers use the beam's w, L, E, I directly.
      2. 
        
    2. Kept private: no clash with another moment() elsewhere.
      3. 
        
    3. Reads like the procedure: moment, then deflection.
      4. 
      
    
    
    
    
    import numpy as np

def beam_response(w, L, E, I):
    """Simply supported beam: load w [N/mm], span L [mm].
    Returns moment [N mm] and deflection [mm]."""
    def moment(x):
        M = w * x * (L - x) / 2      # w, L: from the outer
        return M
    def deflection(x):
        d = w * x * (L**3 - 2*L*x**2 + x**3) / (24 * E * I)
        return d
    x = np.linspace(0, L, 3)     # supports, mid-span
    return moment(x), deflection(x)

M, d = beam_response(20, 6000, 200_000, 3.375e8)
print("Moment [kN m]:", M / 1e6)
print("Deflection [mm]:", d)
# moment(3000)    -> NameError

    
  
    
  
    
The rule: an inner function can read all the local variables (and parameters) of the function it is defined in. Here moment() and deflection() use w, L, E and I from beam_response without receiving them as parameters.
Not the other way round: the outer function cannot see the inner functions' local variables (M, d). It only gets what they return. And the main program cannot call moment() or deflection() at all.
Run the box: moment at the supports and mid-span, maximum 90 kN m = wL²/8 (9×10^7 N mm, divided by 10^6 to print kN m); mid-span deflection 5.0 mm, the same as handout exercise 5.1 (5wL⁴/384EI).
Demo 1: uncomment the last line: NameError: moment is not defined. Demo 2: add print(M) inside beam_response after the inner functions: NameError, the outer cannot see M.
Why nest (engineering): the helpers are formulas for THIS beam, sharing its inputs; keeping them inside avoids passing w, L, E, I to every helper, stops them being used by mistake elsewhere (or clashing with another moment() in a large program), and makes the outer function read like the design procedure.
Caution: nest only when it makes the code clearer. General-purpose helpers (unit conversions, area of a circle) belong at the top level so other code can use them.

Four mistakes cause most problems with functions; two on this slide, two on the next. Run each box, read the message, then fix it.
Calling before defining: Python runs from top to bottom (week 2), so the def has not run yet when cube(3) is called: NameError. Fix: move the def above the call. In a notebook, make sure the cell with the def has been run.

    import numpy as np
def exceeded_sensors(readings, limit=287):
    """
    Sensors whose temperature went above a limit.
    readings: 2-D array, one row per sensor, one column per hour [°C]
    limit: safe limit [°C], default 287
    returns: list of sensor numbers (1 = s1), or None if limit invalid
    """
    if limit <= 0:
        print("The limit must be positive.")
        return None
    peaks = np.max(readings, axis=1)          # one maximum per sensor
    numbers = []
    for number, peak in enumerate(peaks, start=1):
        if peak > limit:
            numbers.append(number)
    return numbers

c_to_f = lambda c: 9 / 5 * c + 32
print(exceeded_sensors(readings))
print(exceeded_sensors(readings, limit=290))
print(exceeded_sensors(readings, limit=-5))
print(c_to_f(np.max(readings)), "°F")

    
  
    
Walk through: the docstring states inputs, units and the return value; the input check returns None for an invalid limit; np.max with axis=1 gives one peak per sensor; the loop collects the sensor numbers into a list, which is returned (not printed), so the caller can use it.
Results: [4, 9, 13] with the default; [4, 9] with limit=290 (keyword argument); message and None with -5; hottest reading about 565 °F.
Because the function returns a list, it can feed other code: e.g. if exceeded_sensors(readings): print("Inspect the engine").
