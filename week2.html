1Introduction

In programming, flow control refers to the order in which statements and instructions are executed. By default, the Python interpreter executes instructions sequentially, from the top of a program or notebook cell to the bottom. Each statement is executed before Python moves to the next statement. The following example demonstrates this standard sequential flow:

45

The value of result is 45 because the expression a + b is evaluated before a is changed. Changing a afterwards does not automatically recalculate result. Step through it to see this happen:

To update the result, the calculation must be performed again:

69

There are many situations in which sequential execution is insufficient. Sometimes, a program must skip some instructions, select one operation from several alternatives, or repeat a calculation. Consider the following examples:

  • A program asks a user for their age using input("Enter your age: ") and determines whether they are eligible for a youth programme. The program must display either "You are eligible" or "You are not eligible", depending on the entered age.
  • A numerical calculation must be repeated for 1,000 time steps. Rewriting the same instructions 1,000 times would be inefficient and difficult to maintain.
  • An iterative engineering calculation must continue until its numerical error falls below a specified tolerance.
  • A program must ignore an invalid sensor measurement without stopping the complete analysis.

The main flow-control structures introduced in this lecture are:

  • Conditional statements: if, elif, and else
  • Loops: for and while
  • Loop-control statements: break and continue
  • Placeholder statements: pass
  • Exception handling: try and except

Indentation is an essential part of Python syntax. Python does not normally use an end command to mark the end of an if statement, loop, or function. Instead, indentation identifies the statements that belong to a code block. The recommended convention is to use four spaces for each indentation level. Most programming editors insert four spaces when the Tab key is pressed. However, spaces and tab characters should not be mixed within the same program. A colon, :, must be placed at the end of the header of a compound statement. For example:

The indented statements belong to the corresponding conditional statement or loop. When the indentation returns to its previous level, the code block has ended.

Do not confuse the assignment operator = with the equality comparison operator ==. The statement temperature = 35.0 assigns the value 35.0 to the variable temperature. 3Conditional statements

Conditional statements allow a program to execute different blocks of code depending on whether specified conditions are true or false. Python uses the following conditional statements:

  • if evaluates the first condition. If the condition is true, the associated code block is executed.
  • elif, which means “else if”, checks an additional condition when all preceding conditions are false. An if statement can contain zero or more elif clauses.
  • else provides a block that is executed when all preceding conditions are false. The else clause is optional and does not contain a condition.

4Loops

Loops allow a block of code to be executed repeatedly. Python provides two principal loop types:

  • A for loop iterates over the elements of an iterable object.
  • A while loop repeats while a specified condition remains true.

4.1 for loops

A for loop is used to iterate over an iterable object, such as a list, tuple, string, dictionary, or range object. For example:

Iteration: 0
Iteration: 1
Iteration: 2
Iteration: 3
Iteration: 4

The loop runs five times. In each iteration, the variable iteration is assigned the next value from range(5).

The expression range(5) does not return a list. It returns a range object that represents the integer sequence from 0 to 4. The final value is excluded. Therefore, range(5) represents five values: 0, 1, 2, 3, 4.

4.1.1 Using range()

The range() function can be used in three forms.

  • Stop value only: this form starts at zero and stops before the specified value, for example range(4). The generated values are 0, 1, 2, and 3.
  • Start and stop values: this form starts from the specified starting value and stops before the specified value, for example range(2, 6). The generated values are 2, 3, 4, and 5.
  • Start, stop, and step values: this form starts from the specified starting value and stops before the specified value; the step size is also controllable. For example, range(0, 10, 2) generates 0, 2, 4, 6, and 8. A negative step can be used to count backwards. For example, range(5, 0, -1) generates 5, 4, 3, 2, and 1.

range() explorer

Leave start or step empty to use their defaults (0 and 1).

The start, stop, and step arguments of range() must be integers. In addition, the step size cannot be zero. Using range(0, 10, 0) raises an error because Python cannot iterate over a sequence with a step size of 0.

Which values does range(2, 10, 3) generate?

Start at 2 and add 3 each time: 2, 5, 8. The next value, 11, is not less than the stop value 10, so it is not generated.

4.1.2 Iterating over a list

A for loop can iterate directly over the elements of a list:

Temperature: 20.5
Temperature: 22.1
Temperature: 25.8
Temperature: 27.3

During each iteration, the variable temperature refers to one element of the list.

4.1.3 Accessing values and indices

The built-in enumerate() function is useful when both the index and the value of each element are required:

0 20.5
1 22.1
2 25.8

By default, enumerate() starts counting from zero. A different starting index can be specified:

Test 1 : 20.5
Test 2 : 22.1
Test 3 : 25.8

4.1.4 Iterating over two lists

The zip() function can be used to iterate over corresponding elements from two or more iterable objects:

Time: 0.0 Displacement: 0.0
Time: 1.0 Displacement: 2.5
Time: 2.0 Displacement: 5.1
Time: 3.0 Displacement: 7.8

This approach is useful when related engineering measurements are stored in separate lists.

By default, zip() stops when the shortest iterable has been exhausted. Therefore, related lists should normally have the same length.

4.1.5 Accumulating results inside a loop

A very common pattern is to build up a result while a loop runs: start a variable at zero before the loop, and add to it on every pass. For example, the total and average of several loads:

Total: 46.0 kN
Average: 11.5 kN

total_load += load is shorthand for total_load = total_load + load, and len(loads) gives the number of elements in the list.

4.2 while loops

A while loop repeats a block of code while a specified condition remains true. For example:

Counter: 0
Counter: 1
Counter: 2

Before each iteration, Python checks whether counter < 3 is true. The statement counter += 1 is equivalent to counter = counter + 1. Updating the counter is essential. Without this update, the condition would remain true, and the loop would continue indefinitely.

This pattern is common in equation solvers, optimisation algorithms, and other iterative numerical methods. A maximum number of iterations should normally be included to prevent an unintended infinite loop:

The calculation converged.

The loop terminates when either the error becomes smaller than or equal to the tolerance, or the maximum number of iterations is reached. This safeguard is important in scientific computing because an iterative method is not always guaranteed to converge.

However, the loop should normally contain a safe termination mechanism, such as a break statement, an external signal, or a controlled shutdown condition. 5Controlling loops

Sometimes, the normal execution of a loop must be changed. Python provides the break and continue statements for this purpose. Python also provides the pass statement. However, pass does not alter the loop flow. It performs no operation and is mainly used as a placeholder.

5.1 The break statement

The break statement terminates the innermost enclosing loop immediately. For example:

The continue statement skips the remainder of the current iteration and proceeds to the next iteration. For example:

When i == 2, the remaining instructions in that iteration are skipped. Therefore, 2 is not printed. An engineering application is ignoring invalid sensor readings:

5.3 The pass statement

The pass statement performs no operation. It can be used when Python requires a statement syntactically, but the intended code has not yet been implemented. For example:

The temperature is within the expected range.

The pass statement does not terminate a loop and does not skip to the next iteration. It must not be confused with break or continue.

continue skips the rest of the current iteration only. break would stop processing every remaining reading, and pass does nothing at all.

Nested loops are useful for parameter studies, matrices, numerical grids, and multidimensional datasets. However, excessive nesting can make a program difficult to read and can significantly increase the computational cost: with 3 lengths and 2 loads the inner block runs 3 × 2 = 6 times, but with 1000 of each it would run a million times.

7Exception handling

An exception is an error detected while a program is running. Examples include invalid user input, division by zero, missing files, and invalid data conversions. If an exception is not handled, Python stops the normal execution of the current program or notebook cell and displays an error message. Python uses try and except to handle expected exceptions. Consider the following example:

Python first executes the statements in the try block. If the entered value can be converted to an integer, the conversion succeeds, and the result is displayed. If int() cannot convert the input, it raises a ValueError. Python then executes the corresponding except block.

Avoid using a bare except: statement unless there is a specific reason to catch every type of exception. Catching a specific exception makes the cause of an error clearer and prevents unrelated programming errors from being hidden. Prefer except ValueError: rather than except:.

8Summary

Flow-control structures determine the order in which program statements are executed. They allow a program to make decisions, repeat calculations, ignore invalid data, terminate an operation, and respond to expected errors. These concepts provide the foundation for implementing numerical algorithms, processing engineering data, checking operating limits, validating user input, and controlling iterative calculations.
